# Iris — static GitHub Pages site

A pure static (HTML + CSS, no build step) landing page for the Iris retail clienteling app: hero, product demo video, screenshot gallery, feature grid, and tech stack.

**Deployment:** served from the `gh-pages` branch at https://xcheljd.github.io/iris/ (private mirror).

**How to redeploy:** update files in this `site/` directory, then copy/commit their contents to the root of the `gh-pages` branch and push `origin gh-pages` — all asset references are relative, so the site works at any base path.
